This repository contains the R `blogdown` source code for constructing the personal website [https://www.kevinwangstats.com/](https://www.kevinwangstats.com/).

---

## 🏗 System Architecture

The project employs a decoupled source/build Git architecture using a Git submodule for generated static assets.

- **Production Site**: Hosted on **Cloudflare Pages**, auto-deployed from commits to `kevinwangstats/netlify_site` (public static build repository).
- **Domain & DNS**: Managed via **Cloudflare Registrar & DNS** (`kevinwangstats.com`).
- **Legacy URL Redirection**: `kevinwang09.github.io` serves client-side JavaScript / HTML redirects to preserve deep links and preserve path structure when redirecting to `https://www.kevinwangstats.com/`.

## 🔄 Build & Deployment Automation (`update_site.sh`)

Site updates and deployments are managed via [`update_site.sh`](file:///Users/kevinwang/projects/kevinwangstats-blogdown-website/update_site.sh):

1. **Path Verification**: Validates that execution is running from `/Users/kevinwang/projects/kevinwangstats-blogdown-website`.
2. **Site Generation**: Executes `R -e "blogdown::build_site()"` to compile markdown/Rmd source files into HTML within `public/`.
3. **Public Repo Sync**:
   - Stages (`git add -A`) and commits (`git commit -m "Update website"`) changes inside `public/`.
   - Pushes `public/` to `kws` (`kevinwangstats/netlify_site`), triggering an automatic Cloudflare Pages deployment.
4. **Source Repo Sync**:
   - Returns to root source repository directory.
   - Stages and commits source updates.
   - Pushes source code to `kws` (`kevinwangstats/blogdown-website`).

## 📋 Instructions for Updating the Website

> **Note**: Execution requires pre-configured SSH keys and R `blogdown` setup.

1. Make edits to the `blogdown-website` source files (`.Rmd`, content, assets, config).
2. Stage and commit your changes in the root repository (`git add`, `git commit`).
3. Run the automated deployment script:
   ```bash
   bash update_site.sh
   ```
